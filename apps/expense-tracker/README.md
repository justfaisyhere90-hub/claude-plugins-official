# Monthly Expenses Tracker

A phone-friendly expense tracker in one HTML file.

**Open it:** https://justfaisyhere90-hub.github.io/claude-plugins-official/apps/expense-tracker/

## Add to your home screen

- **iPhone / iPad (Safari):** Share → Add to Home Screen → Add
- **Android (Chrome):** ⋮ → Add to Home screen (or Install app)

## What it does

- Log expenses by category, with a note and date
- Monthly total, budget meter, category breakdown and 6-month trend
- Recurring entries (rent, phone contract) logged automatically each month
- Backup download (.json), spreadsheet export (.csv) and restore

Data is stored in the browser on your device. Download a backup from ⚙ Settings now and then.
