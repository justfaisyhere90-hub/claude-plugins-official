      Apple Pay payments

      Payments you make with Apple Pay can be collected by an iPhone Shortcut and added here in one go.

      How to set up the Shortcut (once, about 5 minutes)
      1. Open the Shortcuts app → Automation → + → Transaction.
      2. Choose your cards, pick Run Immediately, then Next → New Blank Automation.
      3. Add the action Format Date: date Current Date, format Custom, yyyy-MM-dd.
      4. Add the action Append to Text File. In the text, put: Formatted Date ; Amount ; Merchant (the last two come from Shortcut Input).
      5. Set the file path to wallet-payments.txt and turn on Make New Line. Tap Done.
      6. At the end of the month, tap Import Apple Pay payments above and pick iCloud Drive → Shortcuts → wallet-payments.txt.
